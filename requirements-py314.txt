# ---------------------------------------------------------------------------
# FinSyncAI (MoneyMate) runtime dependencies, curated for Python 3.14.
#
# Why this file exists:
#   The original requirements.txt was exported from a platform running an
#   older Python. On Python 3.14 it cannot resolve because it pins
#   grpcio-status==1.71.2 while google-api-core[grpc]==2.33.0 requires
#   grpcio-status>=1.75.1 (which does not exist for py3.14). That single
#   conflict aborts the WHOLE install, so nothing gets installed and the
#   app crashes with: ModuleNotFoundError: No module named 'dotenv'.
#
# This file lists only the packages the application actually imports,
# at the versions pinned in the original requirements.txt.
# ---------------------------------------------------------------------------
